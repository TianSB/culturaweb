## Decisiones tomadas
- **Estructura de datos:** Se optó por crear los JSON manualmente basados en el PRD en lugar de parsear el SQL dump de WordPress (más rápido para arrancar la UI)
- **Separación lib/:** Se separó `lib/constants.ts` (seguro para client components) de `lib/projects.ts` (solo servidor) para evitar errores de bundling con `fs`
- **Imágenes:** Se configuró `images.unoptimized: true` en `next.config.mjs` para evitar errores de next/image mientras las imágenes no están disponibles
- **Formulario:** Se usó Formspree como backend placeholder (endpoint `YOUR_ENDPOINT`) — pendiente de configuración real
- **Subcarpeta:** El proyecto se creó en `/media/disco_nvme/cultura web/cultura-en-proyectos/` dentro del directorio de trabajo

## Problemas encontrados
- **Error de build con `fs`:** `lib/projects.ts` usaba `fs` y se importaba desde un Client Component (`app/proyectos/page.tsx` con `"use client"`). El bundler de Next.js fallaba al no poder resolver `fs` en cliente. → **Solución:** Separar la página en Server Component (carga datos) + Client Component (recibe props y maneja interactividad), y extraer constantes a `lib/constants.ts`.
- **Directorios no existían:** Al escribir páginas en paralelo, algunos directorios de rutas (`app/proyectos/`, `app/nosotros/`, `app/contacto/`) no se habían creado aún. → **Solución:** Crear directorios primero con `mkdir -p`.
